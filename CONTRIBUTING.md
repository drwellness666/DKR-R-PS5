# Contributing

Found a problem? Use the [issue templates](https://github.com/drwellness666/DKR-R-PS5/issues/new/choose), with the version, active ROM revision, homebrew setup and steps to reproduce. [Known issues](docs/KNOWN_ISSUES.md).

For code changes, explain the problem, resulting behavior and relevant checks. The [developer guide](docs/DEVELOPMENT.md) covers builds and debugging. Preserve original copyright, licences, credits, save data and settings; document new dependencies or artwork.

Do not attach ROMs, extracted game assets, generated CPU code, ROM-containing installers, saves, texture packs, keys or full console dumps. Short source/build diagnostics are welcome.
