# Contributing

Report a reproducible bug or build failure using the issue templates. Include
the port version, active ROM revision, firmware/loader, relevant settings and a
short error excerpt. [Known issues](docs/KNOWN_ISSUES.md) and the
[roadmap](docs/ROADMAP.md) describe current scope.

For changes, explain the concrete problem, resulting behavior and validation.
Keep PS5 adaptations in `src/` or reviewed patches against pinned inputs.
Preserve custom settings and existing saves; keep a previous private build for
recovery. Run the relevant source checks and distinguish host results from
physical console results. See [Development](docs/DEVELOPMENT.md).

Never upload ROMs, extracted game data, generated game code, private builds or
installers, saves/Paks, texture packs or complete console logs. Removing a file
later does not remove it from Git history. Preserve upstream licences and asset
terms; new artwork/fonts need documented sources and redistribution terms.
