# Contributing

Use the issue templates for reproducible game problems or source-build failures.
Include the port version, US revision, firmware/homebrew setup, relevant settings
and a short error excerpt. [Known issues](docs/KNOWN_ISSUES.md).

For code changes, describe the problem, resulting behavior and relevant checks.
Keep PS5 changes in adapters or patches against pinned inputs; preserve settings,
saves and original licences. [Developer guide](docs/DEVELOPMENT.md).

Never attach ROMs, extracted game data, generated CPU trees, private builds or
ROM-containing installers, saves/Paks, texture packs, credentials or full console
dumps. New fonts/artwork need documented sources and applicable terms.
