# RT64 build

Part of the [full source build](BUILD.md). After SDL and the graphics driver:

```bash
export DKR_SDL_WORK="$DKR_PS5_WORK"
export DKR_RT64_WORK="$PWD/work/rt64"
bash build_rt64.sh
```

`RT64_SOURCES.json` pins the renderer, dependencies and Linux shader compiler. The recipe prepares shaders and builds the native archive.

PS5 adapters provide native display handling, paths, clock conversion, thread cleanup and 4K interface scaling. The launch image clears after the first completed presentation. No separate renderer app is needed to play.
