# RT64 build details

Follow README.md or README.de.md for a complete game build. RT64 is one of its
pinned renderer dependencies; a separate renderer-probe installation is not
required. Current gameplay acceptance is in [validation scope](VALIDATION.md).

## Build

After `build.sh` and `build_gpu.sh`, keep their absolute work paths and run:

```bash
export DKR_SDL_WORK="$DKR_PS5_WORK"
export DKR_RT64_WORK="$PWD/work/rt64"
bash build_rt64.sh
```

`RT64_SOURCES.json` fixes the RT64 source, dependencies and Linux DXC tools by
revision and checksum. `build_rt64.sh` generates shaders, builds the native
archive and preserves its source/build receipts in the dedicated work directory.
Modified prepared inputs are refused. It downloads public inputs and performs
no console installation. Compiler and development prerequisites are in README
and GPU_BUILD.md. `CMAKE_BIN` may select the installed CMake executable.

## Platform adjustments

- Plume uses the native display surface and statically linked RADV.
- RT64 has a PS5 native window adapter rather than a desktop SDL Vulkan window.
- Native file selection uses the port's own path/dialog adapter; user ROM input
  is supplied privately on the PC and installed separately on the console.
- Zstd's optional trace hooks are disabled; compression remains available.
- The UTC `timegm` adapter avoids changing process-global time-zone state.
- The prepared emulated-TLS adapter defers cleanup by one pthread-destructor
  round; the original SDK archive is preserved.
- The game supplies ImGui's actual framebuffer scale for full-size 4K menus.
- The launch overlay is hidden after the first completed game presentation.
  Normal own-title termination uses the checked native system-service route.

The bundled synthetic RT64 probe remains optional developer tooling. It contains
no game data and cannot establish DKR gameplay, frame rate or saved progress.
Normal users should build and install the game through the main README.
