# RT64 build notes

RT64 renders the recompiled game. Follow the [build guide](BUILD.md) for the
complete pipeline; a separate RT64 test app is not needed to play.

After building SDL and the graphics driver:

```bash
export DKR_SDL_WORK="$DKR_PS5_WORK"
export DKR_RT64_WORK="$PWD/work/rt64"
bash build_rt64.sh
```

`RT64_SOURCES.json` pins renderer sources, dependencies and Linux DXC tools.
The recipe generates shaders and builds the native archive. It validates inputs,
keeps local preparation receipts and does not install anything on the console.

PS5 changes cover native display/window handling, paths, UTC conversion, SDK
thread-local cleanup and the ImGui framebuffer scale used by 4K menus. The game
clears the launch overlay after its first completed presentation and exits through
the native system-service path.

See [Graphics](GPU.md), [Display](DISPLAY.md) and [Validation](VALIDATION.md).
